# Yubimport

**Öppna sidan:** https://timpan8.github.io/Yubimport/

Skapar CSV-filer med nummerserier. Ange start- och slutnummer (t.ex. `10 000 100` och `10 200 000`) för en eller flera serier. Varje serie laddas ner som en egen fil med kolumnerna `Nummer` och `Info` (alltid `0`), med namnet `Nummer-<start>-<slut>-<datum>.csv`. Väljer du USB-A eller USB-C läggs det till sist, t.ex. `Nummer-<start>-<slut>-<datum>-USB-C.csv`.

Allt körs direkt i webbläsaren. Inget skickas iväg och inget sparas.
